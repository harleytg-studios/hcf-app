Harley's Clan Forum Android v0.4.17c
====================================

Logs & Diagnostics UI refresh
- Rebuilt App Logs as a Logs & Diagnostics screen.
- Added dedicated centered back arrow and compact refresh icon.
- Added Logs / Diagnostics segmented tabs.
- Replaced oversized log controls with compact Refresh, Copy, Export and Clear buttons.
- Removed the oversized bottom Close button; the top back control is now the primary exit path.
- Added searchable logs with All, Info, Warning, Error, Crash, WebView and Network filters.
- Added Grouped mode to collapse repeated identical log events while retaining repeat counts and latest timestamps.
- Added colored INFO / WARN / ERROR / CRASH level rendering and improved timestamp/detail contrast.
- Added an on-device status strip for network state, active forum server, entry count, errors and warnings.
- Added a sanitized Diagnostics tab with app, Android, device, network, forum host, theme, notifications, sync, telemetry, WebView and recovery information.
- Copy and Export now operate on the currently visible Logs or Diagnostics content.
- Clear Logs now requires confirmation and explicitly preserves forum cookies, sessions and settings.
- Recovery UI uses the same normalized native button system.
