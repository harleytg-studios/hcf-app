# Harley's Clan Forum [Beta] — Android Source

Current buildable source for the DEV/Beta Android app.

- Package: `com.harleytg.forum.dev`
- Version: `1.0`
- versionCode: `10000032`
- Min SDK: 26
- Target SDK: 34

## Project layout

- `src/` — Java application source
- `res/` — Android resources
- `assets/` — bundled app assets
- `AndroidManifest.xml` — Android manifest
- `build-release.sh` — DEV release build/signing script
- `app-links/` — Digital Asset Links deployment files

Historical patch notes and duplicate/unreferenced source assets have been removed from this folder. Signing keys and passwords are intentionally not stored in the repository.
