Harley's Clan Forum v1.0 — System-wide Day Theme Fix
=====================================================

Version: 1.0
Version code: 10000017
Internal build: 73
Package: com.harleytg.forum
Channel: Stable

Changes
-------
- Day theme now propagates back to the already-running main forum shell after changing it in App Settings.
- MainActivity detects a theme preference change on resume and recreates the native shell with the correct light/dark resources.
- Day palette now covers previously dark-only native drawables used by settings controls, hero surfaces, URL chrome, and host badges.
- Media Viewer native chrome now follows Day/Night/AMOLED instead of always using black.
- Trusted forum pages receive the app color-scheme hint and a data-hcf-app-theme marker so embedded/web controls do not remain on the previous scheme.
- AMOLED remains true black where explicitly intended.
- Package ID remains com.harleytg.forum and public version remains 1.0.
