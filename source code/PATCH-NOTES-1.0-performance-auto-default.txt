Harley's Clan Forum v1.0 — Auto Performance Default
=====================================================

Internal version code: 10000012

Changes
-------
- Auto is now the default performance profile whenever the user has not explicitly chosen Auto, Performance, Balanced, or Quality.
- The legacy single Performance Mode switch no longer silently forces the new Performance profile during migration.
- Existing explicit four-profile selections remain preserved.
- Public version remains v1.0 Stable.
