Harley's Clan Forum (app) v1.0
================================

This is the release for Harley's Clan Forum (app) v1.0.

Updated
-------
- Public app version remains 1.0.
- Internal Android version code is 10000002 so this build can install over the earlier v1.0 package.
- Account & Identity actions now use the same native row-style controls as App Settings.
- Icons, labels, subtitles, chevrons, padding and touch geometry are consistent across the Account & Identity screen.

What's New
----------
- The release notice now says: "This is the release for Harley's Clan Forum (app) v1.0."
- What's New tracking now includes the internal version code, so this revised v1.0 build can show its release notice once after updating from the first v1.0 build.

Preserved

- Same HCF Release v1 signing identity.
- Contact Support HTG logo/header fix.
- Logs & Diagnostics system UI/clipping fixes.
- Existing updater, notifications, App Links, identity sync, media and recovery behavior.

v1.0 internal revision 10000005
