Harley's Clan Forum v1.0 — System-wide Day/Light Theme Fix v2
===============================================================

Public version: 1.0
Version code: 10000018
Internal build: 74

Fix
---
- Stable and DEV now resolve the selected app theme before Activity.onCreate and before any native page inflates resources.
- Every native Activity inherits from ThemedActivity and receives a Light/Dark/AMOLED-aware base Context.
- values, values-night, styles, drawables, status/navigation bars and native dialogs now resolve from the same selected theme on every app-owned page.
- Switching theme in App Settings recreates Settings immediately; MainActivity detects the preference change when returning and recreates the forum shell.
- Follow phone (Auto) still tracks the Android system night configuration.
- Day (Light) no longer depends on the phone itself being in light mode.
- Existing WebView color-scheme bridge remains enabled for trusted forum pages.
- Trusted Flarum pages now pin FoF Night Mode's actual day/night stylesheet to the app-selected theme, so Day (Light) applies to forum routes as well as native pages without changing the account's server-side night-mode preference.
