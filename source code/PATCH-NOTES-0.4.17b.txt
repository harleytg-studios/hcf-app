Harley's Clan Forum Android v0.4.17b
Version code: 4170001
Package: com.harleytg.forum

Fixed — Contact Support back arrow
- Replaced the legacy Button + compound-drawable back control with a dedicated ImageButton.
- Arrow uses CENTER_INSIDE scaling, equal padding, zero inherited minimum size, and an explicit 44dp touch target.
- Removes text-baseline/font-metric geometry that could make the arrow look shifted or clipped.

Updated — All native buttons
- Added a shared native button geometry helper.
- App Settings, Contact Support, Account & Identity, Cookie Data, and Media Viewer icon-only back controls now use the same centered ImageButton geometry.
- All Java-created text Buttons now opt out of inherited Android minimum width/height and extra font padding.
- Intent chooser, release notes, diagnostics recovery, startup recovery, support, cookie, media, identity, and settings buttons use the normalized behavior.
- XML startup/error buttons and drawer button style use matching minimum-size/font-padding rules.
- Intentional left-aligned action rows remain left aligned; standard action buttons remain centered.

Compatibility
- Package ID remains com.harleytg.forum.
- Version code is 4170001, higher than v0.4.17 (4170000).
- HCF Release v1 signing identity is preserved for direct in-place update.
