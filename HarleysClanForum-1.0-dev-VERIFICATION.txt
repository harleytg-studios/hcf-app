Forum message notification fix
------------------------------
- Nested Messenger/private-message JSON is recursively unwrapped.
- `message`, `body`, `text`, `excerpt`, `preview`, and `content` are treated as user-visible candidates.
- Raw JSONObject/JSONArray containers are never directly converted into notification text.
- `conversation_id` / `conversationId` marks the alert as a conversation message even when the extension uses an unfamiliar notification type.
- Direct-message title: `New message from <sender>`.
- Conversation taps route to `/conversations/<conversation_id>`.
- Safe fallback: `You have a new private message.`
