# Harley's Studios Hardware Guard

No-root Android privacy utility for checking and managing per-app Camera and Microphone permissions through Android's protected system settings.

- Package: `com.harleystudios.hardwareguard`
- Version: `0.1.0` (`versionCode 1`)
- Minimum Android: 8.0 / API 26
- Target Android: API 35
- No root, Shizuku, ADB, analytics, or Internet permission
- Build output: `HardwareGuard-v0.1.0.apk`
