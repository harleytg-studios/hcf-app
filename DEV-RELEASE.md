# Harley's Clan Forum 0.2.0-dev.1

Dev prerelease notes.

## Changes
- New Semantic Versioning format: `0.2.0-dev.1`.
- Automatic update checks on app launch and about every 6 hours in the background.
- Optional automatic APK downloads through Android DownloadManager.
- Install-ready notification after an update download completes.
- Settings includes Check Now, Download Update Now, and Install Downloaded Update.
- Cookie Manager now lists each visible cookie with its name, host, value size, masked/revealable value, and a best-effort purpose label.
- Individual cookies can be cleared separately.
- Existing live forum updates, simplified startup screen, removed bottom bar, and header cleanup remain.
